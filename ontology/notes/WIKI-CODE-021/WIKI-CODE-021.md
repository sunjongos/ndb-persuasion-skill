## 1. 본질
- 정치는 팩트보다 심리(설득 심리)다. 학자·기자·과학자는 팩트가 먼저다.
- 팩트 없이 설득하면 사기꾼, 팩트를 바탕으로 설득하면 사업가·학자·정치가다.

## 2. 2×2 매트릭스

|---|---|---|
| 팩트 O | 리더 | 학자형 (정치에서는 실패형) |
| 팩트 X | 사기꾼 | 무존재 |

## 4. 근거 대조 [해석]
- 아리스토텔레스: 설득 수단은 ethos(말하는 사람 성품)·pathos(듣는 사람 감정)·logos(논증). 학자 = logos, 정치 = ethos·pathos 비중이 큼. 아리스토텔레스도 수사학의 오용 문제를 다뤘다.
- ELM(Petty·Cacioppo 1986): 중심 경로(주장의 질을 따짐) vs 주변 경로(단순 단서). 중심 경로 태도 변화가 더 오래간다 → 대중 정치는 주변 경로가 지배, 학자는 중심 경로.
- 대중 반응 4가지 ↔ 멍거: 싸움 구경·남 탓 ≈ #3 반감, 남 안 되는 것 ≈ #8 시기, 새로운 것 ≈ #6 호기심. 밴드왜건 ≈ #15 사회적 증거(+#14 박탈).
- 치알디니 탐정/밀수꾼 구분은 대표님의 리더/사기꾼 구분과 같은 축이다.

## 7. 심층연구 보강 (WIKI-CODE-022)
### 7.1 핵심 발견 7
1. [자료 내용] 사실을 많이 줄수록 설득된다, 단 정확도와 맞바꾸는 함정: 7.7만 명·AI 19종 실험: 설득력은 정보 밀도에서 나오고, 설득력을 끌어올리는 방법은 하나같이 사실 정확도를 떨어뜨렸다. 사실 근거를 막으면 효과가 크게 줄고, '사실 없이 설득하라' 조건은 효과 73% 감소 [HACKEN2025B][LIN2025][COSTELLO2025] (등급 B)
2. [자료 내용] 태도와 행동은 다른 엔진: 영국 약 1.5만 명 실험: AI 대화가 청원 서명을 약 19.7%p 늘렸으나 태도 변화와 행동 변화 효과는 상관이 없었다. 태도는 정보, 행동은 직접 요청·실행 계획·약속 단계 높이기 [HACKEN2026] (등급 B)
3. [자료 내용] 선거 막판 설득은 거의 효과가 없다: 49개 현장 실험: 본선거 막판 대면·전화 접촉 설득 효과 평균 0에 가까움; 정치 광고 효과도 아주 작음; 심층 대화는 10분으로 몇 달 지속 [KALLA2018][COPPOCK2020][BROOCKMAN2016][KALLA2020] (등급 A)
4. [자료 내용] 사람들은 정보에 합리적으로 반응한다(평행 설득): 지지자·반대자가 같은 방향·비슷한 크기로 움직임; 정정 역효과(backfire)는 대규모 재현에서 거의 없음 → 원연구 D등급 [COPPOCK2023][WOOD2019][NYHAN2021] (등급 A)
5. [자료 내용] 반복은 사실을 이긴다(환상적 진실 효과): 반복해 들은 말은 더 참처럼 느껴짐(d≈0.4~0.5, 초록 기준); 정답을 알아도 완전히 막지 못함 [DECHENE2010][FAZIO2015] (등급 A)
6. [자료 내용] 넛지·손실 프레임은 통념보다 약하다: 학술 논문 평균 8.7%p 넛지 효과가 현장 넛지팀 실험에서 1.4%p; 출판 편향 보정 시 효과 없다는 분석도; 건강 메시지 손실/이득 프레임 차이 거의 없음; 사회 규범 비교 피드백은 현장 재현 [DELLAV2022][MAIER2022][OKEEFE2007][OKEEFE2009][ALLCOTT2011][HALLS2016] (등급 A)
7. [자료 내용] PDF 근거 일부는 재현 위기: 자아 고갈(d≈0.04~0.06, 초록 기준)·행동/돈 점화는 D등급; 초전 설득의 '주의 초점'은 생존, 점화 주장은 엔진 금지; BYAF는 메타분석에서 승낙 확률 약 2배 [HAGGER2016][VOHS2021][DOYEN2012][ROHRER2015][CARPENTER2013] (등급 A)
### 7.2 대표님 원칙에 대한 찬반 증거
**'심리가 팩트보다 강하다'를 지지 (심리 쪽)**
- [자료 내용] 반복이 진실감을 만들고 지식으로도 막지 못한다 [DECHENE2010][FAZIO2015][HASSAN2021]
- [자료 내용] 정체성·감정이 먼저 움직인다(상대 당 혐오 > 정책 차이; 과학 지식이 많을수록 기후 인식이 더 갈라짐) [IYENGAR2012][IYENGAR2019][KAHAN2012]
- [자료 내용] 행동은 정보로 움직이지 않는다(직접 요청·약속, 사회 규범 비교, 이야기 교환) [HACKEN2026][ALLCOTT2011][HALLS2017][KALLA2020]
**'팩트는 약하다'는 통념에 반대 (팩트 쪽)**
- [자료 내용] 사실·정보 밀도가 설득의 주된 엔진; 사실을 막으면 설득이 무너진다 [HACKEN2025B][LIN2025][COSTELLO2025]
- [자료 내용] 반대 진영 정보에도 같은 방향으로 움직이고 역효과는 드물다 [COPPOCK2023][WOOD2019][GUESS2020][TAPPIN2023]
- [자료 내용] 심리 기술 캠페인 효과는 작다(막판 접촉≈0, 네거티브는 신뢰만 하락, 맞춤 타기팅 추가 효과 미미) [KALLA2018][LAU2007][HACKEN2025B][HACKEN2024]
- [자료 내용] 종합: 사실은 엔진, 심리는 변속기.
- [해석] 결론: 행동·정체성·반복의 영역에서는 심리가 강하지만, 태도를 바꾸는 엔진은 팩트다. 설득-정확도 상충은 팩트 게이트의 실증 근거다.
- [해석] 대표님의 '정치는 심리'는 행동·정체성·반복 영역에 한정해 맞고, '팩트 없는 설득은 사기꾼'은 태도 변화 영역과 설득-정확도 상충 실험으로 실증 뒷받침된다.

## 8. 대표님 격언: 하수·중수·고수 (2026-10-25)
> 하수는 팩트 없이 말하고, 중수는 팩트보다 설득에 기대고, 고수는 팩트 위에서 설득해 행동과 결과를 만든다.

| 단계 | 방식 | 결과 |
|---|---|---|
| 하수 | 팩트 없음 | 남는 것 없음 |
| 중수 | 팩트보다 심리 기술 | 일시적 효과, 검증 시 붕괴 |
| 고수 | 팩트+심리+행동 설계 | 신뢰·행동·결과 |

**고수 4단계**
1. 팩트 쌓기
2. 심리로 전달
3. 행동 설계: 구체적 요청·실행 계획·BYAF
4. 결과로 증명(결과가 다음 설득의 팩트)

- [해석] 사분면 대응: 하수 ≈ 사기꾼·무존재(팩트 게이트 BLOCKED), 중수 ≈ 팩트보다 심리(근거 없는 수치·반복·압박 → REVISE), 고수 ≈ 리더 + 행동 설계(BYAF·실행 계획).
- [해석] 연구 연결: 팩트 위 설득 = concept.pr_finding_fact_density, 행동 설계 = concept.pr_finding_attitude_behavior, 중수의 반복 의존 = concept.pr_finding_illusory_truth.
- 개체: principle.ceo_mastery_levels → principle.fact_persuasion_matrix, rule.persuasion_fact_gate
