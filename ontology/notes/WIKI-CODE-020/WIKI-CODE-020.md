## 1. 본질
- [자료 내용] 치알디니 = "남이 나를 움직이는 방식", 멍거 = "내가 나를 속이는 방식". 둘 다 평소엔 맞는 자동 반응(클릭-윙, 표준적 오작동)이 특정 조건에서 오판이 되는 것을 가리킨다.
- [자료 내용] 병원은 시간 압박·피로·위계·불확실성·감정이 겹쳐 자동 반응이 잘 켜지는 곳이다.
- [자료 내용] 여러 경향이 같은 방향으로 겹치면 곱셈(A×B×C×D)으로 커진다(롤라팔루자). 고리 하나만 끊어도 멈춘다.
- [해석] 이 도구들은 WIKI-CODE-021 대표님 원칙(팩트 위에 설득) 아래에서만 쓴다: 공격(설득)에는 탐정 방식만, 방어(오판 예방)에는 감지→분리→구조 3층.

## 3. 자료 핵심 [자료 내용]
- 3기둥: 관계(상호성·호감·연대감) / 불확실성 해소(사회적 증거·권위) / 즉각 행동(일관성·희귀성) + 메시지 이전(초전 설득).
- 8쪽 연결(이미지 확대 대조): 상호성→#9, 호감→#2·#10, 연대감→#2·#12, 사회적 증거→#15, 권위→#22, 일관성→#5·#4, 희귀성→#14·#8, 초전 설득→#16·#18 (12개 경향).
- 멍거에게만 있는 영역: #1·#11·#13·#17·#19~21·#23. 치알디니에게만: 초전 설득·연대감·설득자 윤리·신체 경보·다크 패턴.
- 설득자 3유형: 서투른 자 / 밀수꾼(가짜 희귀성·권위 → 평판 붕괴) / 탐정(진짜 요소만) → 병원 모델 = 탐정.
- 방어 3층: 감지(배·심장 신호, 논리 필터) → 분리(2트랙, 역발상·사전 부검) → 구조(체크리스트, 악마의 변호인, 인센티브 재설계, 유혹 제거, 5W).
- 상담: 금지 = "이번 달까지만", 근거 없는 "다들", 큰 비용 먼저, 빠른 결정 압박. 실천 = 실제 근거·우리 병원 결과, 대안(비수술·경과 관찰), 이유, 집에서 결정할 시간.
- 개인 10문항 점검에서 3개 이상이면 롤라팔루자를 의심하고 멈춘다.
